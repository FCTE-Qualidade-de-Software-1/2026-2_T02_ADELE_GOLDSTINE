# Formulário de Observação do Moderador

Este formulário é preenchido pelo moderador **durante** cada sessão do [teste com usuários](teste-usuarios.md#5-roteiro-da-sessao). Os campos alimentam `dados/brutos/testes-usuarios/sessoes.csv` e `compreensao.csv` ([Planilhas de Coleta](planilhas.md)). Tempos, cliques, primeira escolha e erros **não** são anotados aqui: o avaliador da gravação os registra depois, pelas regras da [seção 8 do protocolo](teste-usuarios.md#8-fim-da-tarefa-e-registro). O SUS e o questionário entregues ao participante estão em PDF preenchível: [questionário SUS](questionario-sus.pdf) e [questionário da Fase 2](questionario-fase-2.pdf).

O formulário preenchido não vai para o repositório. Só os dados transcritos para as planilhas, identificados pelo código do participante, são publicados.

> **Não escreva o nome do participante neste formulário.** Use só o código. Não anote matrícula, programa, disciplina nem professor.
